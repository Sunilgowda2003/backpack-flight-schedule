# ✈️ Backpack Flight Schedule

A React-based Flight Schedule application built using **Skyscanner Backpack UI components**.

## 🚀 Features

- ✈️ Flight Schedule heading
- 📅 Interactive Backpack Calendar
- 🗓️ Date selection
- ◀️▶️ Month navigation
- 🔘 Continue button
- 🧪 Automated test for the Flight Schedule page

## 🛠️ Technologies Used

- React 17
- JavaScript
- Skyscanner Backpack
- Backpack Calendar
- HTML5
- CSS3
- Jest
- React Testing Library
